# התקנת הסקריפט החדש בגיליון (בערך 10 דקות)

הסקריפט עושה ארבעה דברים:
- כותב כל סוג נתון ללשונית משלו בגיליון, כולל העמודה `sessionId`.
- שומר את ההתקדמות של משתמשים רשומים ומחזיר אותה כשמשחזרים במכשיר חדש.
- בונה לשונית "דשבורד" עם סיכום של 30 הימים האחרונים.
- מרענן את הדשבורד אוטומטית כל לילה.

## שלבים

1. **פותחים את הגיליון** שאליו מגיעים היום הנתונים. בתפריט בוחרים **הרחבות > Apps Script**.
2. **שומרים את הקוד הישן.** מעתיקים את כל הקוד שבקובץ `Code.gs` הקיים לקובץ טקסט בצד, ליתר ביטחון.
3. **מדביקים את הקוד החדש.** מוחקים את הקוד הקיים, מדביקים במקומו את כל התוכן של `Code.gs` מהתיקייה הזו, ושומרים (Ctrl+S).
4. **פורסים מחדש באותה כתובת.** חשוב שהכתובת לא תשתנה, אחרת האפליקציה תפסיק לשלוח נתונים.
   1. לוחצים **פריסה (Deploy) > ניהול פריסות (Manage deployments)**.
   2. בוחרים את הפריסה הקיימת ולוחצים על העיפרון (עריכה).
   3. ב"גרסה" בוחרים **גרסה חדשה (New version)** ולוחצים **פריסה**.
   4. ודאו שההגדרות הן "Execute as: Me" ו-"Who has access: Anyone".
5. **יוצרים את כל הלשוניות ומפעילים את הדשבורד.**
   1. בעורך בוחרים את הפונקציה `setupSheets` ולוחצים **הפעלה (Run)**. היא יוצרת מיד את כל 7 הלשוניות: 6 לשוניות נתונים ולשונית "דשבורד". בלי השלב הזה, כל לשונית מופיעה רק כשמגיע אליה הנתון הראשון.
   2. בפעם הראשונה Google תבקש לאשר הרשאות. מאשרים.
   3. בוחרים את הפונקציה `installDailyTrigger` ולוחצים **הפעלה**. מעכשיו הדשבורד יתרענן לבד כל לילה בשעה 3.

## מה ייווצר בגיליון

| לשונית | מה יש בה |
|---|---|
| הרשמות | נרשמים חדשים |
| ביקורים | כל צפייה בדף, כולל `sessionId` |
| חידונים | ציון, ומספרי השאלות שנענו לא נכון |
| שלבים | סימוני "למדתי" |
| משוב | הערות מכפתור המשוב |
| התקדמות | שורה אחת לכל משתמש רשום, עם ההתקדמות השמורה |
| דשבורד | סיכום: נושאים נצפים, ציונים, שאלות שטועים בהן, איפה מפסיקים, מכשירים |

הנתונים הישנים שבגיליון לא נמחקים. הלשוניות החדשות נוצרות לידם.

## בדיקה שהכול עובד

1. פותחים את האפליקציה ונרשמים עם פרטי בדיקה.
2. מסמנים "למדתי" על שלב אחד.
3. ממתינים כ-10 שניות. בגיליון אמורה להופיע שורה בלשונית "התקדמות".
4. פותחים את האפליקציה בדפדפן אחר, ובמסך הבית לוחצים **"🔄 ההתקדמות שלי במכשיר חדש"**.
5. מקלידים את אותו טלפון ואימייל. ההתקדמות אמורה לחזור.

## הערת אבטחה

השחזור מזוהה לפי טלפון ואימייל בלבד, ללא סיסמה. מי שיודע את שניהם יוכל לראות אילו שלבים סומנו ואילו ציונים התקבלו בחידונים, ותו לא. זה מידע לא רגיש, ולכן זו פשרה סבירה לטובת פשטות. אין לשמור בלשונית "התקדמות" שום מידע נוסף.
